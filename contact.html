お問い合わせ

最終更新：2026年11月9日

「暮らしの計算ツール」へのご意見、計算結果の不具合報告、改善提案は、以下のGitHubリポジトリをご利用ください。

GitHub Issuesで報告・提案する（外部サイト）

GitHubアカウントへのログインが必要です。リポジトリ側でIssuesが無効の場合は投稿できません。その場合は運営者のGitHubプロフィールをご確認ください。現時点ではメールフォームは設置していません。

GitHub Issuesでの連絡方法

  1. 上の「GitHub Issuesで報告・提案する」を開きます。
  2. GitHubアカウントでログインします（アカウントがない場合は作成が必要です）。
  3. 「New issue」または「新しいIssue」から内容を入力し、送信してください。

GitHub Issuesは公開されることがあります。個人情報を含むお問い合わせには適していません。現在、非公開の問い合わせフォームやメール窓口は設けていません。

投稿例（コピーしてご利用ください）

件名：【計算結果の確認】〇〇計算ツール

使用したツール：（例：時給計算）
入力条件：（個人情報を含まない仮の数値）
表示された結果：〇〇円
期待した結果・疑問点：〇〇
利用環境：PC／スマートフォン、ブラウザ名（任意）

制度に関する質問では、参照した公的資料のURLも添えていただけると確認しやすくなります。GitHubのアカウントが必要な点は変わりません。非公開の連絡窓口は現時点で提供していません。

報告の際にあると助かる情報

  • 対象の計算機名
  • 問題が発生した操作・入力条件（個人情報を除く）
  • 期待した結果と実際の結果
  • 利用端末・ブラウザ（分かる範囲で）

ご注意：GitHub Issuesへの投稿は公開される場合があります。氏名、住所、メールアドレス、給与明細、口座情報などの個人情報や機密情報は投稿しないでください。
